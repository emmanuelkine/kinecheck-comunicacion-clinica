# Integración con el ecosistema KineCheck

## Posición del producto

Nombre recomendado: **KineCheck Comunicación Clínica - El arte de comunicar en salud**.

La masterclass puede funcionar como formación transversal recomendada para estudiantes y profesionales. No debe bloquear obligatoriamente el acceso a otros productos.

## Enlaces

Los enlaces se encuentran en `data.json`, propiedad `ecosystem`. Configura:

- KineCheck Estudiante
- KineCheck Profesional
- KineCheck Paciente
- Masterclass MSK
- Comunicación en Salud

## Dominio sugerido

- `kinecheck.cl/comunicacion`
- `app.kinecheck.cl/comunicacion`
- `academia.kinecheck.cl/comunicacion`

## Hotmart

Para una primera versión, Hotmart puede entregar el enlace después de la compra. Para una versión comercial robusta, usa un backend que valide el comprador o un proveedor de membresía. Evita publicar claves, tokens o datos de pacientes en el código estático.
