# KineCheck Comunicación Clínica — versión completa

Esta carpeta contiene la versión completa, sin vencimiento, destinada al propietario del producto.

## Abrir localmente en Windows

1. Abre esta carpeta en el Explorador de archivos.
2. Escribe `cmd` en la barra de dirección y presiona Enter.
3. Ejecuta:

```cmd
py -m http.server 8080
```

4. Abre `http://localhost:8080` en Edge o Chrome.

## Publicación

Puede desplegarse como sitio estático en un dominio o subdominio. Para una venta comercial con control real de acceso, debe integrarse con autenticación y un backend; no conviene distribuir esta carpeta directamente a compradores.
