# Identidad 3D KineCheck

Recortes y exportaciones de la imagen transparente aprobada por el propietario el 25-09-2026. No se redibujaron el símbolo, las letras ni el subtítulo. El PNG horizontal de 1944 × 396 px es la versión de mayor resolución que permite la fuente proporcionada. Las exportaciones WebP conservan alfa y usan solo compresión y reducción de tamaño.

| Archivo | Uso |
| --- | --- |
| `kinecheck-3d-horizontal.png` | Materiales educativos y publicitarios; logotipo transparente a resolución original |
| `kinecheck-3d-header.webp` | Cabeceras de escritorio; logotipo y subtítulo |
| `kinecheck-3d-compact.webp` | Cabeceras pequeñas; símbolo y nombre, sin subtítulo minúsculo |
| `kinecheck-3d-symbol-512.png` | Símbolo transparente de alta resolución |
| `kinecheck-3d-symbol-192.png` | Icono de aplicación |
| `kinecheck-3d-symbol-64.png`, `kinecheck-3d-favicon.png` | Iconos pequeños y favicon |
| `kinecheck-3d-social.png` | Vista previa sobre fondo azul marino para enlaces compartidos |

Los bordes alfa se limpiaron de píxeles de transparencia casi nula. El brillo cian del propio diseño aprobado se preservó. Los archivos fuente son recursos estáticos sin llamadas a servicios ni dependencias de ejecución.
