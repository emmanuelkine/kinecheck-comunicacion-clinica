# KineCheck Banderas Clínicas

Integración inicial del curso dentro del ecosistema KineCheck.

- Slug: `banderas-clinicas`
- Acceso: validado mediante la sesión unificada de Academy y la función `course-key`.
- Estado inicial: producto propietario/no comercial.
- Audiencia: profesionales y estudiantes.
- Ruta: `/banderas-clinicas/`.

La habilitación comercial mediante Hotmart se realizará en una etapa posterior, cuando exista un `productId` definitivo y se complete la validación de compra/renovación.
