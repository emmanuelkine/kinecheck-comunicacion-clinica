CERTIFICACIÓN OTEC EN PREPARACIÓN

Información sobre certificación

Los recursos gratuitos de KineCheck no incluyen certificación. KineCheck está preparando un convenio con una OTEC para certificar de forma privada cursos seleccionados una vez que cada programa sea revisado y aprobado bajo los criterios acordados. Cuando el convenio esté activo, el certificado podrá utilizarse como antecedente de capacitación o formación complementaria, sujeto a las bases o criterios de cada institución.

Estado actual: la certificación OTEC aún no se encuentra activa. Estos cursos no corresponden a cursos SENCE, no poseen código SENCE y no utilizan franquicia tributaria.

Solicita la información

Déjanos tus datos y recibirás la información disponible sobre certificación.

El envío de este formulario no otorga un certificado ni constituye una inscripción. Mientras el convenio OTEC no esté formalizado y el programa correspondiente no haya sido aprobado, KineCheck no emitirá ni ofrecerá certificación OTEC. Las horas, requisitos, entidad emisora y demás condiciones se informarán cuando la certificación esté activa para el curso seleccionado.
