# Arquitectura de marca KineCheck

**Estado:** fuente de verdad vigente para nombres, familias y descriptor global.

## Marca principal

La marca principal es **KineCheck**.

El descriptor global obligatorio es:

> **SALUD MUSCULOESQUELÉTICA**

No usar **ECOSISTEMA CLÍNICO** como descriptor de toda la marca.

## Familias y productos

### KineCheck Apps

- **KineCheck Clínico**
- **KineCheck Estudiante**
- **KineCheck Recupera**

### KineCheck Formación

- **Comunicación Clínica**
- **Más allá del Dolor**
- **Evidencia Aplicada**
- **Traumatología y Ortopedia Clínica**

Los nombres propios de estos cursos no se cambian. La relación con la marca puede mostrarse como **KineCheck Formación** o **por KineCheck**.

### KineCheck Packs

- **Pack KineCheck Estudiante**

## Reglas de uso

- Mantener **KineCheck** como marca raíz y no convertir las rutas técnicas en marcas visibles.
- Mantener las asignaciones Apps, Formación y Packs indicadas en este documento.
- No abreviar ni renombrar productos o cursos en superficies comerciales, legales o de acceso.
- Usar **SALUD MUSCULOESQUELÉTICA** cuando una superficie requiera el descriptor global.
- La entrada pública canónica para usuarios con acceso es **`/academy/`**.
- **`/platform/`** se conserva únicamente como ruta técnica de compatibilidad y redirección para enlaces antiguos.

## Control de cambios

Todo cambio de nombre, familia o descriptor requiere actualizar esta fuente de verdad y sus regresiones en el mismo pull request. Los cambios de implementación no autorizan por sí mismos una modificación de marca.
