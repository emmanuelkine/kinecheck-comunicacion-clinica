## Checklist antes de usar la carta

- [ ] El firmante tiene autoridad suficiente o la carta aclara el alcance.
- [ ] El fondo y proyecto están nombrados correctamente.
- [ ] El rol coincide con una conversación previa.
- [ ] Los beneficiarios/cantidad están autorizados.
- [ ] Los aportes tienen respaldo de valorización si las bases lo exigen.
- [ ] No se atribuye patrocinio/certificación inexistente.
- [ ] No se incluyen datos personales de participantes.
- [ ] La carta tiene fecha y contacto institucional verificable.
