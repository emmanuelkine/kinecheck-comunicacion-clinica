## Regla para postular

Antes de enviar cualquier formulario:

1. volver a leer las bases oficiales vigentes;
2. completar el gate legal/tributario del postulante;
3. sustituir escenarios por resultados reales cuando ya existan;
4. confirmar que cada alianza usada en la postulación tenga evidencia documental;
5. validar presupuesto contra ítems elegibles y topes del instrumento;
6. congelar una versión de esta carpeta y guardar los respaldos de la evidencia utilizada.
