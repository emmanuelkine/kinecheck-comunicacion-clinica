Cuéntanos qué ocurrió.

Antes de crear el ticket, KineCheck revisará automáticamente compra, licencia, vigencia, reembolso y sincronización. Si detecta un desfase seguro, intentará corregirlo.

RESCATE DE ACCESO

Primero descarta las dos causas más frecuentes.

Si Hotmart ya aprobó tu compra y KineCheck todavía no reconoce el acceso, este flujo registra el caso sin obligarte a redactar un correo.

1
Confirma el correo exacto de compra

Revisa el mensaje de confirmación de Hotmart y usa exactamente ese correo en KineCheck. Comprueba también Spam, Promociones y si utilizaste una cuenta secundaria.

2
Confirma que el pago diga “aprobado”

Si Hotmart ya lo aprobó, dale hasta 15 minutos a KineCheck para sincronizar. Si el pago sigue pendiente, la liberación depende del método utilizado; algunos pagos no inmediatos pueden tardar varios días hábiles.

3
Si sigue sin aparecer, activa el fast-track

Ten a mano el código de transacción que aparece en el correo de Hotmart. Con esos datos crearemos una solicitud trazable para revisión.

Importante: KineCheck no activa compras pendientes ni reemplaza la confirmación de Hotmart. Si la compra está aprobada y existe una desincronización verificable, el sistema puede intentar conciliarla de forma segura o dejar el caso priorizado para revisión.
No ingreses contraseñas ni datos clínicos identificables. No incluyas RUT, teléfonos, fichas ni imágenes de pacientes.

Si tu pago ya fue aprobado por Hotmart y el acceso no se sincronizó, revisaremos el cruce de datos. Objetivo de respuesta: hasta 12 horas hábiles. Conserva el código de solicitud que aparecerá al enviar.

QUÉ OCURRE DESPUÉS
  1. 1Se comprueba si existe compra y licencia.
  2. 2Se identifica vencimiento, devolución o correo incorrecto.
  3. 3Se intenta conciliar una compra activa desincronizada.
  4. 4Se crea un ticket con prioridad y diagnóstico inicial.

Las solicitudes de privacidad reciben prioridad alta. Para urgencias de salud, utiliza los canales sanitarios correspondientes: KineCheck no presta atención de urgencia.
